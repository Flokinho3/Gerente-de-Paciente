📚 Guia de Funcionalidades

Entenda como usar cada página do sistema

📊 Indicadores

Página principal que exibe gráficos e estatísticas sobre os pacientes cadastrados.

Principais Mecânicas:

  • Gráficos de Indicadores: Visualize 5 indicadores principais de pré-natal em formato de gráficos (pizza, barras, etc.)
  • Abas por Unidade: Cada unidade de saúde tem sua própria aba com gráficos específicos
  • Comparação entre Unidades: Selecione múltiplas unidades e compare indicadores entre elas
  • Comparação de Pacientes: Selecione pacientes específicos para comparar seus dados lado a lado
  • Filtros Dinâmicos: Escolha qualquer campo do banco de dados para criar gráficos personalizados
Acessar Indicadores →

🏆 Ranking de Unidades

Visualize o ranking das unidades de saúde com base nos indicadores de pré-natal.

Principais Mecânicas:

  • Ranking: Unidades ordenadas por desempenho nos indicadores
  • Comparação: Veja e compare os resultados entre unidades
Acessar Ranking →

➕ Novo Paciente

Formulário passo a passo para cadastrar uma nova gestante no sistema.

Principais Mecânicas:

  • Wizard de 17 Passos: Formulário dividido em etapas para facilitar o preenchimento
  • Barra de Progresso: Visualize quantos passos faltam para completar o cadastro
  • Navegação: Use os botões "Anterior" e "Próximo" para navegar entre os passos
  • Validação: Campos obrigatórios são marcados e validados antes de avançar
  • Salvamento: Ao finalizar, clique em "Salvar Paciente" para gravar os dados
Acessar Novo Paciente →

📋 Lista de Pacientes

Visualize e pesquise todos os pacientes cadastrados no sistema.

Principais Mecânicas:

  • Busca em Tempo Real: Digite o nome do paciente na barra de pesquisa para filtrar instantaneamente
  • Cartões de Pacientes: Cada paciente é exibido em um cartão com informações resumidas
  • Paginação: Navegue entre páginas quando houver muitos pacientes
  • Perfil Detalhado: Clique em um cartão para abrir o perfil completo do paciente em um painel lateral
  • Fechar Perfil: Use o botão "×" ou clique fora do painel para fechar o perfil
Acessar Lista de Pacientes →

💾 Exportar

Exporte os dados dos pacientes para arquivos Excel, Word ou texto.

Principais Mecânicas:

  • Seleção de Formato: Escolha entre Excel (.xlsx), Word (.docx) ou Texto (.txt)
  • Filtros por Unidade: Selecione uma ou mais unidades de saúde para filtrar os dados exportados
  • Filtros por Campos: Escolha campos específicos para incluir apenas pacientes que tenham esses dados preenchidos
  • Filtros Combinados: Os filtros funcionam em conjunto (AND) - paciente deve atender todos os critérios
  • Download Automático: Após selecionar formato e filtros, o arquivo é baixado automaticamente
Acessar Exportar →

🗄️ Banco de Dados

Gerencie todos os registros do sistema em formato de tabela.

Principais Mecânicas:

  • Tabela Completa: Visualize todos os pacientes em formato de tabela com todas as colunas
  • Pesquisa: Use a barra de pesquisa para filtrar por nome ou unidade de saúde
  • Editar Registro: Clique no ícone de lápis para editar os dados de um paciente
  • Excluir Registro: Clique no ícone de lixeira para remover um paciente (com confirmação)
  • Backup: Crie uma cópia de segurança do banco de dados completo
  • Restaurar Backup: Carregue um backup anterior para restaurar os dados
  • Sincronização: Sincronize dados entre múltiplos servidores na rede
Acessar Banco de Dados →

⚠️ Conflitos

Resolva conflitos de sincronização entre servidores (pacientes ou agendamentos duplicados ou divergentes).

Principais Mecânicas:

  • Lista de Conflitos: Visualize pacientes e agendamentos em conflito
  • Resolução: Escolha qual versão manter ou como mesclar os dados
Acessar Conflitos →

📅 Agendamentos

Sistema completo para gerenciar agendamentos de consultas dos pacientes.

Principais Mecânicas:

  • Calendário Mensal: Visualize todos os agendamentos em um calendário mensal interativo
  • Navegação de Meses: Use os botões "Anterior" e "Próximo" para mudar de mês
  • Agendamentos do Dia: Clique em um dia do calendário para ver todos os agendamentos daquele dia
  • Adicionar Agendamento: Preencha o formulário com paciente, data, hora e tipo de consulta
  • Busca de Paciente: Digite o nome do paciente para encontrar e selecionar rapidamente
  • Lista de Agendamentos: Visualize todos os agendamentos em formato de lista
  • Editar/Excluir: Modifique ou remova agendamentos existentes
  • Histórico: Acesse o histórico completo de agendamentos passados
Acessar Agendamentos →

🎨 Aparência

Personalize as cores e o tema visual do sistema.

Principais Mecânicas:

  • Editor de Cores: Altere as cores principais do sistema usando seletores de cor
  • Preview em Tempo Real: Veja as mudanças instantaneamente no painel de visualização
  • Grupos de Cores: Organize as cores por categorias (Principais, Texto, Estados, etc.)
  • Salvar Tema: Dê um nome ao tema e salve para uso futuro
  • Resetar: Volte para o tema padrão a qualquer momento
  • Aplicar: As mudanças são aplicadas imediatamente em todas as páginas
Acessar Aparência →
💡 Dica: Use o menu superior para navegar rapidamente entre as páginas. O botão "Ajuda" está sempre disponível em todas as páginas para consultar este guia.
