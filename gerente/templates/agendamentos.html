🤗 Ajuda - Guia Completo do Sistema de Agendamentos

🤗 Respire Fundo, Você Chegou no Lugar Certo!

Sabemos que lidar com agendamentos pode parecer complicado no início...

Mas não se preocupe! Este guia foi feito especialmente para você! 💜

Vamos explicar tudo passo a passo, de forma simples e clara.

1️⃣

📅 Visualizar o Calendário

Para que serve: Ver todos os agendamentos de forma visual, como em um calendário comum.

Como usar:

  • Clique em "Calendário" no menu lateral esquerdo
  • Você verá o mês atual com todos os dias
  • Dias com agendamentos aparecem com uma bolinha colorida 🔵
  • Use os botões "← Anterior" e "Próximo →" para navegar entre os meses
  • Clique em qualquer dia para ver os agendamentos daquele dia específico
💡 Dica: O calendário é atualizado automaticamente quando você adiciona ou remove agendamentos!
2️⃣

➕ Adicionar um Novo Agendamento

Para que serve: Marcar uma nova consulta ou atendimento.

Como usar:

  • Clique em "Adicionar Agendamento" no menu lateral
  • Escolha a paciente: Digite o nome e selecione da lista que aparece
  • Data e Hora: Escolha quando será a consulta
  • Tipo de Consulta: Selecione o tipo (Pré-natal, Retorno, Exame, etc.)
  • Status: Normalmente deixe como "Agendado"
  • Observações: Anote informações importantes (opcional)
  • Clique em "Salvar Agendamento" 💾
⚠️ Importante: Os campos com asterisco (*) são obrigatórios!
3️⃣

📋 Ver Lista de Agendamentos

Para que serve: Ver todos os agendamentos em formato de lista.

Como usar:

  • Clique em "Agendamentos" no menu lateral
  • Você verá uma lista com todos os agendamentos
  • Filtrar: Use os filtros no topo para encontrar agendamentos específicos:
    • Por data (início e fim)
    • Por status (Agendado, Confirmado, Realizado, etc.)
  • Ações disponíveis: Cada agendamento tem botões para:
    • 👁️ Ver detalhes da paciente
    • ✏️ Editar o agendamento
    • 🗑️ Excluir o agendamento
💡 Dica: As estatísticas no topo mostram um resumo rápido dos seus agendamentos!
4️⃣

📜 Histórico de Agendamentos

Para que serve: Ver e confirmar agendamentos que já passaram.

Como usar:

  • Clique em "Histórico" no menu lateral
  • Aqui aparecem agendamentos passados que ainda não foram confirmados
  • Confirmar atendimento: Clique em um agendamento para confirmar:
    • ✅ Foi realizado? Marque como "Realizado"
    • ❌ Não foi realizado? Marque como "Falta" e adicione um motivo
  • Use os filtros para encontrar agendamentos específicos
⚠️ Importante: É uma boa prática confirmar os atendimentos regularmente para manter o histórico atualizado!
5️⃣

🚨 Alertas Automáticos

Para que serve: O sistema avisa você sobre eventos importantes!

Tipos de alertas:

  • 🚨 Alertas de Parto: Aparecem no topo da tela quando uma paciente está próxima da data prevista do parto (últimas 2 semanas)
  • 📅 Agendamentos Próximos: Mostra consultas que estão chegando (próximos 3 dias)

Como usar:

  • Os alertas aparecem automaticamente quando você abre a página
  • Clique no alerta para ver mais detalhes
  • Você pode fechar um alerta clicando no "×"
💡 Dica: Verifique os alertas regularmente para não perder nenhum atendimento importante!

✨ Dicas Rápidas para Facilitar sua Vida

🔍 Pesquisa Inteligente Quando for adicionar um agendamento, comece a digitar o nome da paciente e o sistema vai buscar automaticamente!
🎨 Cores nos Status Cada status tem uma cor diferente para você identificar rapidamente: azul (agendado), verde (confirmado), roxo (realizado), etc.
👁️ Preview Rápido Passe o mouse sobre o nome de uma paciente para ver um preview rápido dos dados dela, sem precisar abrir o perfil completo!
📊 Estatísticas Úteis Na lista de agendamentos, o sistema mostra estatísticas automáticas: total, confirmados, pendentes, etc.
💾 Salvamento Automático Sempre que você faz uma alteração, o sistema salva automaticamente. Não precisa se preocupar em perder dados!
⏰ Lembretes Visuais Agendamentos próximos aparecem destacados no calendário e na lista para você não esquecer!

❓ Perguntas Frequentes

🤔 Como edito um agendamento existente?
Vá em "Agendamentos" ou "Histórico", encontre o agendamento que deseja editar e clique no botão "✏️ Editar". Faça as alterações necessárias e clique em "Salvar Agendamento".
🗑️ Como cancelo um agendamento?
Você tem duas opções: 1) Editar o agendamento e mudar o status para "Cancelado", ou 2) Clicar no botão "🗑️ Excluir" para remover completamente o agendamento do sistema.
📞 O que faço se uma paciente confirmar por telefone?
Vá em "Agendamentos", encontre o agendamento dela e clique em "✏️ Editar". Mude o status de "Agendado" para "Confirmado" e salve. Pronto!
🔍 Como encontro um agendamento específico?
Use os filtros! Em "Agendamentos" ou "Histórico", você pode filtrar por data (início e fim) e por status. Clique em "🔍 Aplicar Filtros" para ver apenas os agendamentos que você procura.
👤 Como vejo os dados completos de uma paciente?
Clique no nome da paciente em qualquer agendamento. Um modal vai abrir mostrando todos os dados cadastrados, incluindo informações pessoais, gestacionais, histórico médico, etc.
⚠️ E se eu cometer um erro?
Sem problemas! Você sempre pode editar qualquer agendamento. Se excluir por engano, infelizmente não há como recuperar (então tome cuidado ao excluir). Mas criar um novo agendamento é rápido e fácil!
🎯 Qual a diferença entre os status?
  • Agendado: Consulta foi marcada mas ainda não confirmada pela paciente
  • Confirmado: Paciente confirmou que virá (por telefone, WhatsApp, etc.)
  • Realizado: Atendimento já aconteceu
  • Cancelado: Consulta foi cancelada (por você ou pela paciente)
  • Falta: Paciente não compareceu ao atendimento
